设备名 (BLE / mDNS)

用作 BLE 广播名和 mDNS 主机名的基础。留空则自动生成 (Stackchan-XXXXXX)。mDNS 只会保留英文字母、数字和连字符。保存后重启生效。

音频输出

jtts 音色

留空或不改就点「保存」，会保留当前设置。

HMM 音色（.htsvoice）/ 单元拼接语音库（.jvox）可在 Wi-Fi 设置页上传。

语音引擎（hts_engine, Modified BSD）与配布音色的归属： 许可证 / 归属

偏柔和的参考：开合比 0.65–0.75 / tilt 6–12 dB / 带宽 1.2–1.5 （加气息 0.1–0.25）。均在 v2 方式下有效（带宽在经典方式下也有效）。

格式为 画面文字 | 读音。| 右侧（读音）只能写平假名或片假名 （汉字在发音时会被忽略）。省略 | 则画面文字与读音相同。 示例: 画面文字 | 平假名读音

音频文件播放（BLE 流式传输）

选择本地音频文件（.mp3 / .wav / .m4a / .aac 等）再点「播放」， 浏览器会重编码为 24 kHz 单声道 AAC-LC，再经 BLE 流式发送。 Stack-chan 边解码 AAC 边播放，并按音量张嘴。

⚠ 对话功能已开启，无法使用。无线和 CPU 会互相抢占导致播放中断，两者互斥。 请关闭「启用对话功能」并保存重启后再用。

触摸操作

应答播放中点按形象屏幕（头部）可打断 AI 应答。触摸传感器较灵敏，容易误触，所以默认关闭。抚摸（前→中→后连续触摸）与本开关无关，始终开启。保存后重启生效。

设备功能开/关

在形象画面左上角显示电量条（保存后重启生效）

启动后是否播放 C5–E5–G5（扬声器自检音）。关闭则静音启动（保存后重启生效）

关闭后不上舵机电源，也不启动舵机任务（保存后重启生效）。与操作画面的卸力/恢复开关不是一回事，本项会写入 NVS 持久保存。

舵机原点与活动范围（面向 Takao base 等自制底板）

舵机安装方向和活动范围因底板而异。请设置原点（0..1023）和活动范围（度）， 再点「保存并重启」生效。默认是 M5 base 的数值。

打开范围设置模式后舵机会卸力，可以手工摆到目标位置再采集。 请按顺序：正中点「采集 Yaw 原点」，左端点「采集 Yaw 最小」，右端点「采集 Yaw 最大」。 采集值会填进上方输入框。最后点「保存并重启」确认。

猫耳 LED

设置猫耳 NeoPixel（GPIO9 / 18 颗 LED）的模式、颜色和亮度。 更改立刻生效，并自动写入 NVS，重启后仍会恢复。 彩虹（gradient）模式会忽略颜色。

形象张嘴时 LED 会跟着反应（对话播放、jtts 发音、麦克风口型同步都有效）。关闭时固定为所设亮度。保存后重启生效。

开启时选择控制方式。「亮度」是嘴张得越大 LED 整体越亮的原有行为。 「电平表」把猫耳三角形（LED1 为底边，LED5 为顶点） 当成 5 级条形图点亮。保存后重启生效。

Claude Code Channel (MCP)：令牌管理

设置后会启用 /mcp/* HTTP API（可由 Channel adapter 连接）。清空后 /mcp/* 返回 404。保存后重启生效

固件更新 (OTA)

从 GitHub Release 选择，或选本地 build/stackchan_idf.bin， 再点「写入」，会经加密 BLE 把新固件写到另一分区并重启。 成功后浏览器侧 BLE 会断开，请手动重新连接。
